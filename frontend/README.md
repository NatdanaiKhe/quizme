# Quizme — Frontend

React + Vite single-page application for Quizme daily quizzes, stats, and topic management.

## Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Lint
npm run lint

# Build for production
npm run build
```

## Configuration

Copy `.env.example` to `.env` if custom API URL is needed:
- `VITE_API_BASE`: Backend API base URL (default: `http://localhost:8080`).
